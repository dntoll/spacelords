# Bordningsytor

Krav: `rumsspecifika-bordningstexturer`, `texturerad-vaggovansida`.

Sju original skapades med inbyggd bildgenerering och sparas i
`assets/original/boarding/`. Kör `python3 scripts/prepare-boarding-surfaces.py`
för att bereda WebP-bilderna till klienten. Resultaten granskades som enskilda
bilder och i bordningsstriden och editorn, även med mobilformat.

Gemensam stil: mörk blågrå skeppsmetall med cyan och dämpade bärnstensfärgade
ljus, realistisk industriell sci-fi, ortografiska ytor utan text eller perspektiv.
